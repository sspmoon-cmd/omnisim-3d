# 🌐 OmniSim 3D : 세상의 모든 상황 시뮬레이터

> **"현실에서 후회하지 마세요. 당신의 뇌와 심장을 위한 초현실 3D 가상 리허설 룸"**  
> *Hyper-Realistic 3D Simulation Platform for Decision Making, Psychology & Life Scenarios*

---

## 🌟 프로젝트 개요
**OmniSim 3D**는 Three.js 기반의 초현실 3D 인터랙션과 강화학습(MDP) 심리 프레임워크를 결합하여,  
로또·확률, 야식 충동, 사직서 제출, 소비 갈림길 등 일상의 다양한 딜레마 상황을 3D로 미리 겪어보고 최적의 선택을 돕는 웹/앱 플랫폼입니다.

## 🚀 빠른 시작 (Local Run)
별도의 빌드 과정 없이, 웹 브라우저(Chrome 권장)로 아래 HTML 파일을 더블클릭하시면 즉시 3D 시뮬레이터를 조작하실 수 있습니다:
1. `visual_demo_concepts.html` (100명 군집 시뮬레이터 & 미래 영수증)
2. `index.html` (3D 가상 회의실/면접실)

## 🛠️ 기술 스택
- **3D Engine**: Three.js, OrbitControls, GSAP
- **3D Modeling & PBR**: Blender
- **Physics**: Cannon-es / Rapier.js (Browser Native, API 비용 0원)
- **Deployment**: GitHub Pages / Cloudflare Pages
